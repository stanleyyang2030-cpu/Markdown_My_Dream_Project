# My Dream Coding Project: EcoTrack🌱
## Project Overview
**EcoTrack** is an app designed to help users *track their daily carbon footprint* and make samll, sustainable choices that add up to a big impact. 

It's built using **HTML**, **CSS** and **JavaScript**

---
## Project Goals
- Build a user-friendly dashboard that trakcs:
    - 🌿 *Energy use*
    - 🚗 *Transportation Impact*
    - 🍔 *Food consummption patterns*
- Display personalized reports using:
    - `console.log()` to debug progress

        ```
        if (carbonScore < 50) {
             console.log("Great job staying eco-friendly!");
             } else { 
               console.log("Legt's find ways to reduce your footprint!");
             }
        ```
